# Project Status Schema

A project status record should answer:

- Where is the modeling process now?
- What blocks progression?
- Which human decisions are pending?
- What evidence supports completion?
- What is the next valid action?

## Status ownership

The system may calculate status from evidence and contracts.

The system may recommend next actions.

The system may not approve assumptions, final models, risk acceptance, or paper claims.

## Next action priority

Priority order:

1. resolve blocking modeling decisions;
2. complete missing validation;
3. freeze evidence package;
4. enable paper generation.
