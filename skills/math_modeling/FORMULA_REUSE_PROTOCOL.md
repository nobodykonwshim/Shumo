# 公式复用与模型边界审查协议

本协议是 `skills/math_modeling/SKILL.md` 的补充约束，用于避免数学建模论文在后续问题中重复定义已经建立过的公式、变量和模型。

## 1. 职责边界

通用数模 Skill 只保存写作规则、流程约束和审查脚本，不保存具体赛题的公式库、参数库和项目模型数据。

具体赛题或项目应在项目目录下建立自己的登记库，例如：

```text
2024A/registry/parameters.yaml
2024A/registry/formulas.yaml
2024A/registry/model_contracts.yaml
```

## 2. 核心原则

数学建模论文应区分“已有模型”和“本问新增模型”。已经在前一问或前文中建立过的基础公式，后续问题只能引用、调用或说明其参数替换，不得再次完整推导或重复展开。

必须遵循以下规则：

1. 基础模型只在首次出现的问题中完整建立；
2. 后续问题若需要使用该模型，应写“沿用式……”“调用前文模型……”或“将前文模型中的参数替换为……”；
3. 每一问只新增解决本问目标所必需的变量、约束、目标函数、判定函数和求解算法；
4. 输出 LaTeX 前必须审查是否重复出现已有公式、已有坐标表达、已有递推关系或已有碰撞判定模型；
5. 若发现重复定义，应立即改写为引用式表述，不得继续输出重复模型。

## 3. 写作前强制检查流程

每次撰写新问题前，必须先完成以下检查：

```text
第一步：读取项目参数库，确认参数、单位和编号；
第二步：读取项目公式库，列出前文已经建立的基础公式和模型；
第三步：读取项目模型边界库，明确本问允许新增和禁止重复定义的内容；
第四步：正文中只写本问新增内容，已有模型用式号引用；
第五步：输出前检查是否出现禁止重复表达。
```

推荐在每一问开头加入边界说明，例如：

```latex
本问沿用前文已经建立的位置递推模型与碰撞判定模型，不再重复给出基础轨迹方程、坐标表达和实体几何构造公式，仅针对本问新增的优化变量和可行性判定函数进行建模。
```

## 4. 项目公式库建议格式

项目公式库建议放在：

```text
<project>/registry/formulas.yaml
```

公式库至少记录以下内容：

```yaml
formula_id:
  label: "eq:xxx"
  name: "公式名称"
  latex: "公式 LaTeX"
  meaning: "公式含义"
  first_defined_in: "首次出现的问题或章节"
  reuse_rule: "后续是否只允许引用"
  forbidden_redefine: true
```

## 5. 项目参数库建议格式

项目参数库建议放在：

```text
<project>/registry/parameters.yaml
```

参数库至少记录：

```yaml
parameter_id:
  symbol: "参数符号"
  value: "数值"
  unit: "单位"
  meaning: "含义"
  source: "题面/计算结果/假设"
```

## 6. 项目模型边界库建议格式

项目模型边界库建议放在：

```text
<project>/registry/model_contracts.yaml
```

每个问题都应有独立的模型边界：

```yaml
problemX:
  must_reference:
    - "必须沿用的已有公式或模型"
  forbidden_redefine:
    - "禁止重复推导的公式或模型"
  allowed_new_models:
    - "本问允许新增的模型"
  review_before_output:
    - "输出前必须检查的项目"
```

## 7. 通用审查脚本

通用审查脚本位于：

```text
skills/math_modeling/checks/check_formula_reuse.py
```

使用时必须传入项目自己的模型边界库，例如：

```bash
python skills/math_modeling/checks/check_formula_reuse.py \
  --contract 2024A/registry/model_contracts.yaml \
  --problem problem3 \
  --tex sections/problem3.tex
```

## 8. 输出前审查清单

在输出任意一问 LaTeX 之前，必须逐项检查：

```text
是否读取了项目参数库？
是否读取了项目公式库？
是否读取了项目模型边界库？
是否重复写了前文已经定义的轨迹方程？
是否重复写了前文已经定义的坐标表达？
是否重复写了前文已经定义的弧长函数？
是否重复写了前文已经定义的实体几何模型？
是否重复写了前文已经定义的碰撞判定模型？
本问是否只新增了当前问题真正需要的新变量、新约束和新目标？
公式标签是否与项目公式库冲突？
正文是否使用“沿用式”“调用前文模型”“参数替换”等引用式表述？
```

只要其中任一项不满足，应先修改，不得直接交付。

## 9. 优先级

本协议的优先级高于“章节自洽性”。后续问题为了自洽可以简述前文模型用途，但不得重复展开前文公式。若“完整性”和“避免重复”冲突，应优先避免重复，并通过式号引用保证完整性。
